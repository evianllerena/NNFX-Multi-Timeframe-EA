# Docs

| File | Role |
| --- | --- |
| `RULEBOOK.md` | What the EA does: every NNFX rule with its source and label (A / B / C) |
| `SPEC.md` | How it runs on 30M / 1H / 4H, and how every part is verified |
| `DECISIONS.md` | Decision log |
| `ENVIRONMENT.md` | Facts about the MT5 terminal and broker |
| `CHANGELOG.md` | Repo changes by date |

`RULEBOOK.md` and `SPEC.md` are exported snapshots of the owner's living Claude Docs
(rulebook exported at revision 58, spec at revision 26, both on 2026-10-03). When a
living doc changes, a new snapshot is committed with a CHANGELOG line, so the repo
always records which version the code was built against.
